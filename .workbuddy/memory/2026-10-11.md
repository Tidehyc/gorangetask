# 2026-10-11 GoRangeTask

## 项目需求确认（读 docs 四份文档后）

- 项目：**GoRangeTask**，可嵌入 Go 服务的 MySQL 事务型持久化任务队列。
  核心＝业务数据与任务行**同一事务**提交/回滚，任务表即投递通道，不依赖 RabbitMQ。
- module：`github.com/Tidehyc/gorangetask`（gh 账号 Tidehyc，token 有效）。
- MVP 只支持 MySQL 8.0+/InnoDB（`SKIP LOCKED` + 行锁领取）；至少一次语义 + Handler 幂等。
- 核心包不依赖 GORM；另出**可选 GORM adapter 子包**。
- 状态机：`pending/running/succeeded/dead/canceled`；所有写回校验 affected rows（0 行=失去任务）。
- 关键字段：lease_owner / lease_until / **lease_epoch(fencing)** / attempt / max_attempts / run_at / idempotency_key。
- 交付阶段：①规格确认 ②持久化闭环 ③并发与恢复 ④失败处理 ⑤验证与观测 ⑥可选外部集成。
- 参考 River / Asynq / pgq（只借鉴设计，不复制代码）。

## 本地 MySQL 环境（本次搭建）

- 决策：**不用宿主机的 mysql**，改用**容器化干净实例**，避免污染本机。
- 实测宿主：**未安装 mysql-server**（无 `/var/lib/mysql`、无自启软链），3306 未被占用 → 无需停服务。
- 容器：`gotask-mysql`（image `mysql:8.0`，server **8.0.46**），卷 `gotask-mysql-data`，
  映射 `127.0.0.1:3306:3306`，库 `gotask`，root/`rootpw`，
  参数 `--default-time-zone=+00:00 --transaction-isolation=READ-COMMITTED --character-set-server=utf8mb4`。
  校验：version=8.0.46 / isolation=READ-COMMITTED / time_zone=+00:00 / UTC_TIMESTAMP 正常 / buffer_pool=128MB。
- 管理脚本：`scripts/dev-mysql.sh {up|down|reset|status|shell}`（已 chmod +x）。
- 坑：`MySQL 8.0` 官方镜像 init 阶段会先起临时 server（`port: 0`）再重启最终 server，
  必须等**最终** server 就绪（`mysqladmin ping -h127.0.0.1`）再连，否则报 `Lost connection ... error: 2`。
- 坑：容器内 `mysql -uroot` 走 socket 会被拒绝（MYSQL_ROOT_PASSWORD 下 root@localhost 仅…），
  用 `-h127.0.0.1 --protocol=TCP` 即通。

## 公开 API 类型定义（提交 57be84f）

- 根包 `gorangetask`（package gorangetask），文件：`doc.go`（包文档）、`task.go`、`errors.go`、
  `handler.go`、`client.go`（**尚未拆 store/ 子包，按需求“先保持小而清晰的公开 API”**）。
- `task.go`：`TaskID uint64`；`Status string` + 5 常量 `pending/running/succeeded/dead/canceled`
  及 `IsValid()`/`IsTerminal()`；`Task`（入队输入：Queue/Type/Payload/RunAt/MaxAttempts/IdempotencyKey）；
  `TaskInfo`（查询结果，含 Attempt/LastError/CreatedAt/UpdatedAt/FinishedAt 等）。
  注意：`Task` **不含 Timeout 字段**（需求 §7 草案里有，但技术设计 §6 的 API 草案里没有；
  已记入待与用户确认）。
- `errors.go`：`ErrDuplicateTask/ErrNotFound/ErrNotPending/ErrNoHandler/ErrInvalidPayload/ErrInvalidTask/ErrLeaseLost`。
- `handler.go`：`Handler func(ctx, json.RawMessage) error`；`Registry`（RWMutex，Register 拒绝空类型/nil/重复，
  Lookup/Has/Types/Len）。
- `client.go`：`Tx` 接口**只暴露 `ExecContext`**（刻意不含 Commit/Rollback）；
  `Client` 接口 = Enqueue/EnqueueTx/Get/Cancel。
- 测试：`task_test.go` + `handler_test.go`，**10 用例全过，`-race` 通过，语句覆盖率 100%**。

  （随便放持久磁盘即可），已建 `/home/tide/.cache/go-tmp`。
